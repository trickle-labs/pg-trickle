# v0.105.2: Package, upgrade, performance, and field validation

> **Status:** Planned
> **Scope:** Large
> **User promise:** *"The released build works in the environments we support."*
> **Blocked by:** [v0.105.1](v0.105.1.md)
> **Series:** [v0.105.x](v0.105.x.md)

## Theme

Validate the packaged v0.105 series with active data, supported upgrades,
foreground-write workloads, and operator procedures. This release does not
start the deferred v1.0 qualification.

## Work

- Build every supported package reproducibly and run install and maintenance
  smoke tests against the packaged artifacts.
- Run the supported upgrade and recreation paths with active stream tables and
  pending source changes.
- Measure refresh throughput, p95 and p99 latency where useful, memory, WAL,
  output-log growth, and foreground-write impact.
- Verify that disabled output-delta consumers add no work beyond the documented
  budget.
- Have independent operators run install, diagnose, alter, upgrade, restore,
  and resnapshot procedures on the documented packages.
- Record field-validation results, known limitations, and supported responses.
- Add patch releases only when a release blocker or compatibility defect
  requires one.

## Exit criteria

- [ ] Every supported package installs and maintains real stream-table data.
- [ ] Every supported upgrade or recreation path passes with pending changes.
- [ ] Workload results meet the frozen foreground-write and refresh budgets.
- [ ] Package, upgrade, and field evidence names the exact candidate artifact.
- [ ] Every remaining limitation has a stable diagnostic and supported
      response.
- [ ] No 72-hour soak or longevity run is required by this release.

## Deferred qualification

The 72-hour mixed-workload soak, the longer-running longevity environment,
`v1.0.0-rc.1`, later release candidates, and `v1.0.0` remain unscheduled.
Schedule them in a future qualification plan when the project resumes the
stability-release work.

## Scope control

Do not add SQL features, capabilities, integrations, or autonomous controller
actions. Keep the v0.104.0 public contracts frozen.
