# v0.105.2 full implementation details

**Status: Released (2026-09-11).** v0.105.2 ships PostgreSQL 18 packages,
packaged Linux runtime checks, static upgrade checks, and Criterion benchmark
smoke tests.

## Qualification boundary

The [post-release assessment](../pg-trickle-v0.105.2-assessment.md) identifies
gaps between the intended qualification and executed checks. The release path
does not establish all-platform runtime qualification, live previous-package
upgrades, foreground-write budgets, or independent operator validation.
[v0.106.0](v0.106.0.md) and [v0.107.0](v0.107.0.md) address those gaps after
the corrective [v0.105.3](v0.105.3.md) patch.

## Completed work

- ✅ Done — package metadata, Docker defaults, archives, and the
  v0.105.1 → v0.105.2 upgrade path are version-synchronized.
- ✅ Done — the packaged Linux candidate runs Graph V1, Delta V1, DVM,
  recovery, WAL, snapshot, and diagnostics suites. Upgrade checks validate SQL
  chain completeness rather than a live previous-binary upgrade.
- ✅ Done — quick Criterion benchmark smoke runs before release publication.
- ✅ Done — release evidence records the candidate commit, supported artifact
  metadata, checksums, PostgreSQL version, suite results, and retained logs.
- ✅ Done — documented release, upgrade, rollback, and operator procedures are
  checked as part of the release gate.

## Deliberately deferred

The 72-hour mixed-workload soak, seven-day longevity environment, release
candidates, and v1.0 release remain deferred to later qualification work.
