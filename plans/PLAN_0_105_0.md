# v0.105.0 implementation plan

## Objective

Create a candidate-bound qualification contract for the frozen v0.104.0
public surface. Make runtime conformance and release evidence enforceable.

## Scope

- Add the v0.105.0 qualification manifest and schema checks.
- Add a release gate for exact suite, version, artifact, and evidence rules.
- Run Graph V1 and Delta V1 conformance against the packaged candidate.
- Reconcile the v0.104.0 checklist with executed evidence.
- Add package, archive, changelog, version, and upgrade artifacts.

Do not add SQL features, capabilities, integrations, or release-candidate
work. Do not require the 72-hour soak or longevity run.

## Implementation order

1. Add `tests/release/v0.105.0-qualification.json`.
2. Add `scripts/v0_105_0_release_gate.py`.
3. Extend `scripts/release_evidence.py` to require every suite in the
   qualification manifest and bind results to the candidate artifact.
4. Wire `just test-v104-conformance` into the release qualification workflow.
5. Add the v0.105.0 version and upgrade artifacts without changing SQL objects
   unless a release blocker requires a fix.
6. Update the v0.104.0 evidence and release documentation.

## Acceptance criteria

- The manifest contains no wildcard version for the v0.105.0 candidate.
- Required suites cannot be represented by a text marker or an implicit skip.
- Release evidence records the candidate commit, artifact digest, PostgreSQL
  version, suite version, workload, and retained logs.
- The packaged Graph V1 and Delta V1 suite passes in CI.
- A missing, skipped, unavailable, stale, or failed required result blocks
  publication.
- The 72-hour soak and longevity run are explicitly deferred and non-blocking.

## Verification

- `just fmt`
- `just lint`
- `just test-unit`
- `just test-v104-conformance`
- `just check-upgrade-all`
- `python3 scripts/v0_105_0_release_gate.py`

## Deliverables

- `tests/release/v0.105.0-qualification.json`
- `scripts/v0_105_0_release_gate.py`
- release-workflow and release-evidence updates
- v0.105.0 package and upgrade artifacts
