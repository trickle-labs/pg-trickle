# ADR-005: Private State for Set-Operation Multiplicity

| Field | Value |
|-------|-------|
| **Status** | Accepted |
| **Date** | 2026-08-15 |
| **Deciders** | pg_trickle core team |
| **Category** | DVM correctness / storage |

## Context

`INTERSECT` and `EXCEPT` need branch multiplicities even while a tuple is
invisible in the user result. Storing those counters in the stream table leaks
implementation columns and cannot represent the required `ALL` bag semantics
without changing the PostgreSQL-visible result shape.

## Decision

Store canonical positional tuples and left/right multiplicities in permanent,
LOGGED private state relations registered by the stream table catalog. Apply
state changes and visible result deltas in one refresh transaction. Use
NULL-safe value equality for correctness; a row hash is only an accelerator.

## Consequences

Direct reads preserve PostgreSQL's output columns and duplicate multiplicity.
Private state has a lifecycle and corruption/reinitialization contract, and
state relations consume additional storage.
