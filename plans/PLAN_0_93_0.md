# v0.93.0 Implementation Plan

The canonical release contract is
[roadmap/v0.93.0.md](../roadmap/v0.93.0.md). This plan covers the public
contract and ownership foundation for composable graph refresh. Strict graph
refresh is deferred to v0.94.0, and output-delta consumption is deferred to
v0.95.0.

## Work order

1. GV1-1: Add independent capability discovery for graph refresh and output
   delta consumption.
2. GV1-2: Add deterministic typed stream-table and graph contracts with
   generations, digests, source identity, dependency closure, and database
   instance identity.
3. GV1-3: Persist `MANAGED` and `EXTERNAL` orchestration ownership, including
   create, alter, repair, drop, status, scheduler, dump, restore, and upgrade
   behavior.
4. GV1-4: Enforce owner-equivalent authorization, safe search paths, RLS
   boundaries, role dependencies, and fail-closed handling for unsupported or
   malformed graph state.
5. Add the upgrade migration, archive SQL, conformance coverage, operational
   documentation, and the v0.93 release gate.

## Validation

- Run `just fmt` and `just lint` after Rust changes.
- Run `just test-unit` after Rust changes.
- Run targeted integration and E2E tests for contracts, authorization,
  scheduler admission, recovery, backup/restore, and upgrade behavior.
- Run `just check-version-sync`, `just check-meta-version`, and
  `just v0-93-release-gate` before changing the roadmap status or opening the
  pull request.

## Exit criteria

- [ ] Both capabilities are discoverable independently without package-version
      inference.
- [ ] Stream-table and graph contract fixtures pin encoding, generations,
      closure, ordering, and digest behavior.
- [ ] Unsupported cycles, source classes, temporary relations, cross-database
      references, malformed catalogs, and unauthorized access fail closed.
- [ ] `EXTERNAL` ownership survives restart, backup/restore, failover, clone
      activation, and supported upgrade without scheduler dispatch.
- [ ] Lifecycle and dump paths cannot silently transfer ownership or refresh an
      external graph.
- [ ] Security coverage includes hostile `search_path`, RLS sources, mixed
      owners, role drop/reuse, and private-relation disclosure.
