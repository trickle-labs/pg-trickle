# v0.103.0 implementation plan: durable WAL receipt and workload control

**Status:** Implemented

## Delivered scope

- Durable, replayable WAL receipts are persisted before slot acknowledgement.
- Receipt replay is idempotent and records a committed receipt and acknowledgement
  high-water mark per source.
- WAL admission is re-enabled only through the receipt-backed path; trigger CDC
  remains the fallback for ineligible or failed sources.
- Scheduler admission keeps using the existing worker quotas and deadlines.
- Release workload budgets and the offline release gate are frozen with the
  versioned package metadata.

## Deliberate scope boundary

This release does not add a second resource-profile system or claim universal
low latency under overload. The existing worker quotas, lock timeouts, statement
deadlines, backpressure, and freshness evidence remain the control surface.
