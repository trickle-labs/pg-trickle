# v0.92.0 Implementation Plan

The canonical release contract is
[roadmap/v0.92.0.md-full.md](../roadmap/v0.92.0.md-full.md). This plan keeps
the implementation order and exit criteria in one place while v0.92.0 is
developed.

## Work order

1. LC-4: Persist capture ownership identity and fail closed on clones.
2. LC-7: Classify capture failures and guard recovery against unproven
   frontiers.
3. LC-5: Add machine-readable upgrade preflight and quiescence APIs.
4. LC-3: Add restore/promotion validation and recovery documentation/tests.
5. LC-6: Add the bounded upgrade support manifest, migration, and CI coverage.

## Validation

- Run `just fmt` and `just lint` after every code change.
- Run `just test-unit` after Rust changes.
- Run targeted integration/E2E tests for catalog, CDC, recovery, and upgrade
  changes.
- Run `just check-version-sync` and the v0.92 release gate before opening the
  pull request.
