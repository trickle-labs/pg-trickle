# v0.104.0 Implementation Plan

## Objective

Make Graph V1 and Delta V1 stable public SQL contracts with a small, executable
conformance boundary and freeze the release surfaces around it.

## Scope

1. Admit both capabilities without the retired experimental gate.
2. Preserve graph refresh identity and source-boundary provenance in durable
   history and output-delta batches.
3. Exercise discovery, transactional publication, rollback, resnapshot, typed
   payload reads, and cursor acknowledgement through public SQL only.
4. Freeze package, upgrade, documentation, capability, and release-gate files.

Remote delivery, a stable Rust ABI, and a connector marketplace remain outside
this release.
