# v0.102.0 implementation plan: output-sensitive delta evidence

**Status:** Implemented for the evidence and reporting scope.

## Delivered

- Record bounded differential-refresh evidence in
  `pgt_refresh_history.refresh_reason_detail`.
- Report input delta rows, changed output rows, output amplification, source
  row estimates, scan count, plan identity, cache path, planner hints, temp
  blocks, and phase timings.
- Keep the existing PostgreSQL planner and current rewrite set unchanged.
- Add a pure unit check for output-amplification evidence.
- Add the release gate, capability example, upgrade script, and package
  metadata for v0.102.0.

## Deliberate scope boundary

This release does not enable a new rewrite rule. The stored evidence makes
high-fanout cost visible and provides the measurements needed before admitting
key restriction, predicate pushdown, or join-order changes in a later release.
Missing evidence leaves the current plan unchanged.
