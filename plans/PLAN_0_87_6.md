## Exit criteria

- [x] Every failed CI case uploads a standalone reproducer.
- [x] The regression corpus and mandatory semantic coverage run on every pull

- [x] Supported strategy and CDC variants converge to the direct query result.
- [x] Every failpoint preserves the last committed correct result and later
      convergence.
- [x] Every active negative control is detected by the release gate.

## Notes

COR-17's shrinker reduces cycles then mutations, greedily, re-verifying each
candidate against a live database. Row/column/query-branch/operator/type/
constraint/execution-setting-level shrinking is intentionally deferred — see
the `ponytail:` note at the top of `scripts/dvm_shrink.py` — cycle- and
mutation-level reduction already collapses a padded corpus failure down to
its minimal reproducing cycle/mutation, which is what the exit criterion
needs.

COR-19's failpoint test reuses the existing `pg_trickle.test_chaos_for_table`
TEST-MODE hook (added for D-3 auto-suspension testing) rather than adding new
engine-level fault injection — no `src/` changes were needed for this
release.
