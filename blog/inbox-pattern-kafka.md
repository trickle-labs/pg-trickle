# The Inbox Pattern: Receiving Events from Kafka into PostgreSQL

This article describes the former managed inbox API. For the supported manual
inbox pattern, see the [Inbox documentation](https://github.com/trickle-labs/pg-trickle/blob/main/docs/INBOX.md).

The standalone inbox and relay now belong to the [`pg_tide` project](https://github.com/trickle-labs/pg-tide).
